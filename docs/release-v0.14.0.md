# True GOAT v0.14.0 更新报告

2026 年 10 月 8 日

这次更新让“为什么他排在这里”更容易看懂：点开一个维度，就能查看原始数据和计算过程；评价冠军时，也能查看夺冠路上实际遇到的对手。球员库与排名实验室同步开放全部 6,717 份已收录档案。

**点开维度，看懂每一分。** 在[排名实验室](https://j0ey2ou.github.io/true-goat/)点击维度名称、说明、雷达图轴或数值表，即可打开详情。弹窗展示原始统计、参考百分位、内部权重、逐项贡献和计算公式，并提供可搜索、可翻页的该维度球员排名。原始指数、对手调整后的指数，以及这一项对你当前总分的实际贡献分别展示，方便逐层核查。

**同时代对手与冠军路径进入评价。** 新增的对手调整默认开启，也可以一键关闭。常规赛与季后赛会考虑实际同场对手的赛季场均得分、同代实力排名，以及该场出场时间。对手实力排名通过稳定的迭代计算得出，并固定在数据快照中；不会因为你收藏了一位球员或改变 GOAT 系数而反复循环变化。

总冠军的评价也增加了路径信息：对有可靠证据的夺冠赛季，按该球员实际参加的季后赛所遇对手调整团队成就指数。详情中可查看冠军赛季、对手球队、路径强度、同代基准及冠军系数。缺少路径证据时保留原值，不把未知当成较弱的冠军。

这些系数和调整上限是公开的模型选择，**不是官方定论**。它们衡量遇到的对手，也不等同于直接防守对位或个人夺冠贡献。对手数据覆盖 NBA / BAA 的已收录比赛，**截至 2023–24 赛季**；不将这一截止日期延伸到后续赛季，也不把 NBA 对手系数套用于缺少对应资料的 CBA、欧洲球员。关闭调整后，可以继续比较原始指数。

**全球球员目录开放全部已收录档案。** [球员库](https://j0ey2ou.github.io/true-goat/players.html)与排名实验室默认载入 6,717 位去重球员，无需逐个添加。可以按联赛、数据覆盖、中文名、英文名和绰号查找，并分页浏览。

| 已收录联赛经历 | 球员数 | 当前范围 |
| --- | ---: | --- |
| NBA / BAA | 5,217 | 历史实际常规赛出场档案与现役阵容快照 |
| CBA | 1,637 | 已核实历史出场档案与国内球员注册快照 |
| EuroLeague | 18 | 官方资料中已收录的部分球队球员 |

同一球员可能有多个联赛经历，表中人数不能直接相加。这是跨联赛目录的**现有覆盖，不是全球全部篮球运动员的完整名单**。身份只按已核实映射合并，不凭同名猜测。仅有基础档案的球员仍可检索；缺少可比数据时保持未知或未评分，不编造分数，也不把部分数据包装成完整七维评价。

**补齐姓名，保留资料边界。** 使用 347 份已审校姓名映射，补齐原 300 位球员的中英文显示，并完善简体中文、繁体中文和英文的档案、公式及缺失说明。没有可靠译名时保留来源姓名并提示，不临时拼造译名，也不改动原始统计。

**定制数据更容易上手。** [定制数据](https://j0ey2ou.github.io/true-goat/custom.html)新增直接找亮点的入口，操作指引改为球迷可以照着做的步骤。结果用连贯的自然语言说明“谁在什么范围、满足什么条件、取得什么表现”；比较范围、并列情况、依据和缺失说明继续保留在结果弹窗及分享文本中，不把只有一人的样本说成有竞争性的第一。

**兼容已有使用记录。** 旧自选名单继续作为浏览器内收藏，取消收藏不会将球员移出全库。旧模型链接仍可读取，新模型链接可以携带对手调整设置。本次更新无需数据库迁移。

**验证情况。** 已通过 162 项单元测试、12 项静态构建测试，以及桌面、手机和简中／繁中／英文浏览器检查；覆盖维度弹窗、全库筛选与分页、缺失数据、姓名与中文链接、模型兼容及定制数据流程。上述结果是功能与构建验证，不代替发布后的线上检查。

English overview: v0.14.0 makes dimension scores auditable, adds optional same-season opponent and verified championship-path adjustments, and opens all 6,717 collected profiles in the lab and directory. Opponent evidence runs through 2023–24; missing data and unverified names remain explicit. Previous favorites and model links remain compatible, and no database migration is required.
